# OpenFin8:BR - README

**Brazilian open finance (Open Finance Brasil): consent resources,
PIX payment initiation, automatic payments + enrollments.**

OpenFin8:BR is the Brazilian adapter over the openfin8-core kernel:
the Central-Bank-mandated open-finance ecosystem - consent-resource
sharing with per-resource permissions, hard expiry + deletion
obligations, PIX instant payments, and the enrollment-based
recurring model. The ceremony is FAPI-BR: the Open Finance Brasil
Directory + ICP-Brasil mTLS + detached JWS signing.

[`DESIGN.md`](https://github.com/OpenFin8/openfin8-br/blob/main/DESIGN.md)
defines the BR wire, the consent lifecycle mapping, the PIX money
movement, and the registration/configuration surface.
